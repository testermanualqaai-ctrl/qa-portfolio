# Bug Report — Checkout Available Without Products

## Summary
User can proceed to checkout without adding products to cart.

## Environment
- Browser: Chrome
- OS: Windows 11
- Device: Desktop

## Steps to Reproduce
1. Login to SauceDemo
2. Open cart without products
3. Click Checkout

## Expected Result
Checkout should be blocked when cart is empty.

## Actual Result
User can continue checkout process without products.

## Severity
Medium

## Priority
Medium

## Notes
This bug is also detected by automated negative test TC-0009.
